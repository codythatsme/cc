cc is an independent fork of [bb](https://github.com/get-bb/bb), originally created by Michael Yong and contributors. It retains the upstream MIT license and attribution.

Install the macOS desktop app with `brew install --cask codythatsme/tap/cc`.

The fork removes telemetry and uses local bundled plugins. Remote connect and community marketplaces require explicit configuration. Releases and source are available on [GitHub](https://github.com/codythatsme/cc).
