Let CC browse, click, fill out forms, and check web pages for you. Control the in-app browser or run headless browsers on your local and remote machines connected to CC.

Headless sessions include live inline previews in the chat, so you can watch CC work and expand the preview for a closer look. In-app browser sessions stay visible in CC's browser panel.

Enable Browser Automation in plugin settings, then ask CC to open a page, test a flow, or verify a change.
